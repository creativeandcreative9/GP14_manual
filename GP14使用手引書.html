はじめに

ポーズスタジオでできること

ポーズスタジオは、Unity の中で、人型のアバターにポーズを付ける道具です。

できたポーズは、そのまま写真や動画に撮れます。

ポーズスタジオで、ポーズを付けて撮った写真です。

  • ポーズの絵をクリックするだけで、アバターにポーズが付きます。
  • 手や足の印を引っぱると、うでや足がついてきます。
  • プレイモード（Unity でゲームを動かす状態）に、入らなくても使えます。
  • 保存したポーズは、ほかのアバターにも使えます。

安心して試せます

  • まちがえても、窓の上の［↶］で 1 つ前に戻せます。窓かシーンビューを触っているときは、Ctrl+Z でも戻せます。かんたん表示の［からだを動かす］では、［元に戻す］を押します。
  • マイポーズの［消す］だけは、戻せません。
  • ポーズを付けたり撮ったりしても、アバターに、ポーズスタジオの部品は付きません。アップロードのじゃまをしません。VRChat 用の仕掛けを入れたときだけ、アバターに物や設定が入ります（「VRChat で使う」）。
  • アバターの元のファイル（モデルやプレハブ）は、書きかえません。
  • ポーズを同じ名前で保存すると、名前のあとに番号が付きます。前のポーズは上書きされません。［くわしい保存］では、上書きする前にたしかめる画面が出ます。

必要なもの

  • Unity 2022.3。VRChat 用のアバターなら、VRChat が決めた版（2022.3.22f1）をおすすめします。
  • 人型（Humanoid）として設定された、アバターのモデル。
  • VRChat SDK は、なくても使えます。あると、VRChat 用の機能が増えます。
  • ポーズスタジオは、BOOTH の商品ページで手に入ります。

手順の数

入れ方は 6 手順、はじめての練習は 10 手順です。

先に知っておく言葉

  • シーンビュー: Unity の真ん中にある、アバターを見る画面です。
  • ヒエラルキー: Unity の左にある、置いてある物の一覧です。
  • プロジェクトウィンドウ: Unity の下にある、ファイルの一覧です。
  • 人型（Humanoid）: 頭・うで・足の骨を、Unity が見分けられるアバターです。
  • 印（ハンドル）: シーンビューに出る、引っぱるための四角や丸です。

画像の見方

赤い枠と数字は、押す場所か、見て確かめる場所です。数字は、下の手順の番号と同じです。画像に無い番号の手順は、前の画像と同じ場所を押します。

苦手なこと

ポーズスタジオにも、苦手なことがあります。買う前に、ここでたしかめてください。

使えるアバター

  • 人型（Humanoid）でないモデルには、ポーズを付けられません。動物の形などで、人型の設定ができないものは使えません。

動き・揺れ

  • ポーズは、止まった形を作る道具です。歩くなどの動きを、1 から作る道具ではありません。ポーズとポーズの間を、なめらかにつなぐ動画は作れます。
  • 髪やスカートの揺れは、止まった形として整えます。PhysBone の揺れを見るには、VRChat SDK（3.10.5 以降）が要ります。

VRChat の中

  • カメラのほうを見るポーズは、VRChat の中では作れません。VRChat SDK が入っているプロジェクトでは、ポーズに入れた目の向きで止めることはできます。
  • 明るさや画面の効果を、VRChat の中で変える機能はありません。写真のときは、Unity の中の撮影の設定を使ってください。

書き出し

  • 動画を MP4 で書き出すには、ffmpeg（動画を作る無料のソフト）が要ります。なくても、GIF と PNG で書き出せます。

確かめた環境

  • Windows 11、Unity 2022.3.22f1。
  • Linux（Ubuntu 22.04）、Unity 2022.3.22f1。
  • ほかの環境では、まだ確かめていません。

入れ方

ツールを手に入れます

  1. BOOTH の商品ページで「ポーズスタジオ」を買い、ZIP ファイルをダウンロードします。

  2. ダウンロードした ZIP ファイルを解凍します（Windows では右クリックの「すべて展開」、Mac ではダブルクリック）。中に PoseStudio.unitypackage があることを、たしかめます。

Unity に入れます

先に、アバターが入っている Unity のプロジェクトを、Unity Hub から開いておきます。Unity の版は、Unity Hub のプロジェクトの一覧に出ます。2022.3 で始まる版なら使えます。

  1. PoseStudio.unitypackage をダブルクリックします。

    Unity の上のメニューから、［Assets > Import Package > Custom Package...］を選んでも同じです。

  2. 取り込む物の一覧の窓が出ます。上に「PoseStudio」と出ます。すべてに印が付いたまま、右下の［Import］を押します。

  3. 読み込みが終わるまで、待ちます。取り込みの窓と、進み具合の表示が消えたら終わりです。

入ったことを、たしかめます

このパソコンで初めて入れたときは、ポーズスタジオの窓が自動で開きます。

  1. 開かないときは、Unity の上のメニューから［Tools > Pose Studio > Open］を選びます。

窓が開けば、入っています。メニューが出ない・赤いエラーが出るときは、困ったときを見てください。

新しい版を入れるとき

新しい版の PoseStudio.unitypackage を、上と同じ手順で入れます。

古い版を消す必要はありません。保存したポーズも残ります。

入れたあとにエラーが出たときは、プロジェクトウィンドウの「Packages」の中の「Pose Studio」を消してから、入れ直します。取り込みの窓では、同じ物が「com.」で始まる名前で出ます。

はじめての練習

アバターにポーズを付けて、写真を 1 枚撮ります。

練習なので、どのアバターでも大丈夫です。アバターがないときは、練習用のマネキン（人の形の人形）を出せます。

アバターを入れます

  1. ヒエラルキーで、ポーズを付けるアバターをクリックします。アバターがヒエラルキーに無いときは、プロジェクトウィンドウからアバターのプレハブを、ヒエラルキーへドラッグして置きます。

  2. Unity の上のメニューから、［Tools > Pose Studio > Open］を選びます。

    窓が開き、アバターが自動で入ります。シーンビューに、アバターの全身が映ります。

    アバターがいないときは、窓の［試し用のマネキンを出す］を押します。

ポーズを付けます

  1. 窓の［ポーズをえらぶ］を押します。

  2. ポーズの絵の中から、「手を振る」をクリックします。アバターが、手を振るポーズになります。

手を動かします

  1. 窓の［からだを動かす］を押します。シーンビューの手と足に、緑の四角が出ます。

  2. 右手の緑の四角を、上へ少しドラッグします。アバターがこちらを向いているときは、画面の左側の手が右手です。うでが、ついてきます。

  3. ［元に戻す］を押します。手が、動かす前に戻ります。Ctrl+Z でも戻せます。

写真を撮ります

  1. 窓の［写真］を押します。

  2. ［写真を撮る］を押します。シーンビューの向きで撮れます。写るのはアバターだけで、緑の印や床は写りません。

  3. ［保存先を開く］を押すと、撮った写真のフォルダが開きます。

写真は、プロジェクトのフォルダの中の Screenshots/PoseStudio に保存されます。

できあがりの例です。背景の色は、場面や設定で変わります。

うまくいかないときは、困ったときを見てください。

できあいのポーズ

できあいのポーズを当てたい

できあいのポーズは、ポーズスタジオに入っているポーズです。

［ライブラリ］タブで、絵の一覧から選ぶと、アバターにそのポーズが付きます。

先に、窓を開いてアバターを入れておきます。やり方は「はじめての練習」の手順 1 と 2 です。

かんたん表示で当てるときは、［ポーズをえらぶ］タブを使います。「はじめての練習」の手順 3 と 4 と同じです。

ポーズを当てます

  1. 窓の左上の［くわしく］を押します。

  2. ［ライブラリ］タブを押します。

  3. 一覧の上の［ポーズ］を押します。すでに選ばれているときは、そのままで大丈夫です。

  4. 好きなポーズの絵をクリックします。アバターに、そのポーズが付きます。

一部だけ、少しだけ当てます

  1. ［反映度］のスライダーを動かします。

    1 だと、ポーズが全部入れかわります。0.5 だと、今のポーズと半分ずつ混ざります。

  2. 部位の［上半身］を押します。

    上半身だけが変わり、脚は今のままです。

  3. もう一度、ポーズの絵をクリックします。

    ［反映度］と部位は、絵をクリックしたときに使われます。

できあがり

絵を押すたびに、ポーズが変わります。気に入らないときは、窓の上の［↶］を押します（Ctrl+Z でも戻せます）。

自分で保存したポーズは、［マイポーズ］に出ます。保存のしかたは、ポーズの保存の章を見てください。

気をつけること

  • アバターが入っていないと、「アバターを選んでください。」と出て、ポーズは付きません。
  • ［反映度］が 1 より小さいときは、押すたびに、今のポーズと混ざります。
  • ポーズが付いたあとの細かい直しは、手足を引っぱる章と関節を回す章を見てください。

手足を引っぱる

手足を引っぱって、ポーズを直したい

シーンビューに出る緑の印を、マウスで引っぱります。手や足を引っぱると、うでや脚がついてきます。

印は、手・足・ひじ・ひざ・頭・腰・胸にあります。

先に、窓を開いてアバターを入れておきます。やり方は「はじめての練習」の手順 1 と 2 です。

かんたん表示の［からだを動かす］タブでも、手足を引っぱれます。［左右対称］などは、［くわしく］で使います。

手を動かします

  1. 窓の左上の［くわしく］を押します。

  2. ［ポーズ］タブを押します。

  3. ［手足を引っぱる］を押します。シーンビューの手と足に、緑の四角が出ます。

  4. 右手の緑の四角に、マウスを乗せます。名前と動かし方が出ます。

  5. 緑の四角を、動かしたい方へドラッグします。うで全体がついてきます。

ひじやひざの向きを変えます

  1. 右ひじの、緑の小さな丸をドラッグします。

    手の位置はそのままで、ひじの向きが変わります。ひざも同じです。

ほかの印

  • 足の四角: 脚ごと動かします。
  • 腰の四角: 足を残して、体を動かします。しゃがんだり、寄せたりできます。
  • 胸の印: 上半身を曲げます。
  • 頭の印: 顔と目を、その方へ向けます。

左右そろえたいときは、先に［左右対称］を押します。片側を動かすと、反対側も鏡のように動きます。

手や足の向きを変えるときは、［回転］を押してから、手や足の印をクリックします。回すための輪が出ます。

できあがり

手を上げたり、足を開いたりしたポーズになります。戻すときは、窓の上の［↶］を押します（Ctrl+Z でも戻せます）。

気をつけること

  • うでや脚の長さより遠くには、手や足が届きません。
  • 動かしたくない手足は、印を右クリックして、［ロック（引っぱっても動かさない）］を選びます。
  • その位置に残したい手足は、［その場に留める（位置を固定）］を選びます。
  • どの関節でもつかんで引っぱりたいときは、［体ごと引っぱる］を使います。
  • 少しずつ回したいときは、関節を回す章を見てください。

関節を回す

関節を少しずつ回して、細かく直したい

関節は、ひじやひざのように、体が曲がる所です。

関節を 1 つ選ぶと、回すための輪が出ます。［+］と［−］で、決めた角度ずつ動かすこともできます。

先に、窓を開いてアバターを入れておきます。やり方は「はじめての練習」の手順 1 と 2 です。

輪で回します

  1. 窓の左上の［くわしく］を押します。

  2. ［ポーズ］タブを押します。

  3. ［関節を回す］を押します。シーンビューに、関節の丸い印が出ます。

  4. 回したい関節の印を、クリックします。右ひじを選ぶと、ひじに輪が出ます。

  5. 輪をドラッグします。ひじが回ります。

関節の印をドラッグすると、その関節の親の骨が、そちらを向きます。ひじなら、上うでが向きます。

数字で調整します

  1. 窓の［数値で調整］の見出しを押します。欄が開きます。すでに開いているときは、押さなくてかまいません。

  2. ［± の1回］の横で、［1°］を押します。

  3. ［曲げ伸ばし］の行の［+］を押します。右ひじの［曲げ伸ばし］の角度が、1° 変わります。押し続けると、続けて動きます。

スライダーを、直接ドラッグしてもかまいません。スライダーの名前は、関節ごとに変わります。ひじなら、［曲げ伸ばし］と［ひねり］です。

できあがり

関節が少しずつ回り、ポーズが細かく直ります。戻すときは、窓の上の［↶］を押します（Ctrl+Z でも戻せます）。

気をつけること

  • Ctrl+クリックで、関節を 2 つ以上選べます。同じ向きの曲がりが、同じだけ動きます。
  • 輪の向きが分かりにくいときは、［関節の向き］と［上下左右］で切り替えます。
  • 腰は、［体幹と体の向き］で動かします。
  • 指は、［手］タブで動かします。手の形の章を見てください。
  • スライダーの数は、角度ではなく、−1 から 1 の値です。角度は、スライダーの右に出ます。
  • スライダーの端より先には、動きません。

手の形

指や手の形を変えたい

手の形は、［手］タブで変えます。5 本の指をまとめて握ったり、指を 1 本ずつ曲げたりできます。

先に、窓を開いてアバターを入れておきます。やり方は「はじめての練習」の手順 1 と 2 です。

ピースやグーのような、できあいの形もあります。それは、この章の終わりに書きました。

5 本の指をまとめて動かします

  1. 窓の左上の［くわしく］を押します。

  2. ［手］タブを押します。左手と右手の欄が出ます。

  3. 動かしたい手の［握り］のスライダーを、右へ動かします。5 本の指が、握る形になります。

  4. 同じ欄の［開き］のスライダーを動かします。指と指の間が、広がったり閉じたりします。

  5. ［親指の向き］の四角の中を、ドラッグします。横で親指の開き、縦で付け根の曲げが決まります。

窓がせまいときは、先に［両手］、［左手］、［右手］のどれかを押して、出す手を決めます。

指を 1 本ずつ動かします

  1. 指の名前の横にある、左のスライダーを動かします。その指が、曲がったり伸びたりします。

  2. その右のスライダーを動かします。その指が、横に開いたり閉じたりします。

  3. 指の名前（例: ［人差し指］）を押します。関節ごとの調整が開きます。

シーンビューで動かします

  1. 指先の緑の丸を、ドラッグします。指が曲がったり、伸びたりします。

  2. 指の関節の丸をクリックすると、回すための輪が出ます。

丸が小さいときは、シーンビューを拡大します。全身に戻すときは、［アバターを映す］を押します。

できあいの形、左右、保存

  • できあいの形は、［ライブラリ］タブの［手］で選びます。かんたん表示では、［ポーズをえらぶ］タブの［手のサイン］です。
  • 左手の欄の［右手へ写す］を押すと、左手の形が、右手に鏡のように写ります。右手の欄には、［左手へ写す］があります。
  • ［リセット］を押すと、その手の指が、曲げ・開きのない標準の形に戻ります。
  • ［手の保存］に名前を入れて［手を保存］を押すと、今の手の形が残ります。［ライブラリ］の［マイハンド］に出ます。

できあがり

握った手や、指をさす手ができます。戻すときは、窓の上の［↶］を押します（Ctrl+Z でも戻せます）。

気をつけること

  • ［左右対称］が押されていると、片手を動かしたとき、反対の手も同じになります。
  • 左右を別々にしたいときは、［左右対称］をもう一度押して、外します。
  • 手の形を付けても、腕や体の形は変わりません。

表情

表情を付けたい

表情は、ボタンを 1 つ押すだけで付きます。この章は、かんたん表示を使います。

表情は、顔の動き（シェイプキー）の組み合わせです。アバターの顔に、笑顔や、ウィンクの形が付きます。

先に、窓を開いてアバターを入れておきます。やり方は「はじめての練習」の手順 1 と 2 です。

ボタンで付けます

  1. 窓の左上の［かんたん］を押します。

  2. ［表情］タブを押します。「基本」「ネガティブ」「驚き」「口の形」「目」の順に、ボタンが並びます。

  3. 付けたい表情のボタンを押します。例えば、「基本」の［笑顔］です。アバターの顔が、笑顔になります。

  4. 別のボタンを押します。前の表情のボタンで動かした顔の動きが戻って、新しい表情に変わります。

困ったとき

様子から探します。

メニューに［Tools > Pose Studio > Open］が出ない

  • どうなっているか: Console に赤いエラーが残っていると、メニューが出ないことがあります。
  • どうすればよいか: 赤いエラーを先に直します。直らないときは、入れ方をやり直します。

入れたあと、更新のあとに、赤いエラーが出る

  • どうなっているか: 入れかえが、うまくいっていないかもしれません。
  • どうすればよいか: プロジェクトウィンドウの「Packages」の中の「Pose Studio」を消して、入れ直します。

ハンドル（印）がシーンビューに出ない

  • どうなっているか: アバターが入っていないか、タブが開いていないのかもしれません。
  • どうすればよいか: ［アバター］の欄で、アバターを選びます。かんたん表示は［からだを動かす］、くわしく表示は［ポーズ］を開きます。

「人型として使えなくなった」と出る

  • どうなっているか: アバターが、人型（Humanoid）の設定ではなくなっています。
  • どうすればよいか: モデルをクリックし、「Rig」の「Animation Type」を「Humanoid」にします。「Apply」を押して、アバターを選び直します。

プレイモードに入ると、ポーズが戻る

  • どうなっているか: プレイモードでは、アバターの動きの仕組みが、ポーズを上書きすることがあります。
  • どうすればよいか: ポーズは、プレイモードに入らずに作ります。［VRChat］タブの［共存の状態］に原因が出るときは、そこにある［アバターの動きの再生を止める］などを押します。

表情のボタンを押しても、顔があまり動かない

  • どうなっているか: 合うシェイプキー（顔の動き）が少ないのかもしれません。プレイモードでは、アバターを軽くするツールが、シェイプキーを消すことがあります。
  • どうすればよいか: ［顔の動きを名前で探す（くわしい人向け）］で、近いものを探せます。

［動画］タブで MP4 が選べない

  • どうなっているか: ffmpeg（動画を作る無料のソフト）が見つかっていません。
  • どうすればよいか: ffmpeg を入れます。そのあと、［再検出］を押します。GIF は、そのまま使えます。

［写真を撮る］を押しても、写真が撮れない

  • どうなっているか: 画面に、理由と直し方が出ます。
  • どうすればよいか: 出た文のとおりにします。保存先は、［撮影］タブの［出力（大きさ・画質・保存先）］で変えられます。

写真やポーズが見つからない

  • どうなっているか: 保存先は、決まったフォルダです。
  • どうすればよいか: 写真は［保存先を開く］で開けます。ポーズは、［ライブラリ］の［マイポーズ］に出ます。［くわしい保存］の分は、Assets/PoseStudio/Poses です。

元に戻したい。Ctrl+Z が効かない

  • どうなっているか: Ctrl+Z が働くのは、ポーズスタジオの窓かシーンビューを触っているときだけです。ほかの窓では、Unity の元に戻すが動きます。
  • どうすればよいか: 窓の上の［↶］を押します。はじめの姿に戻すときは、［ポーズ］タブの［リセット］で［開いたときのポーズ］を押します。

窓を閉じても、アバターがポーズのまま

  • どうなっているか: 閉じても、ポーズが残る設定です。
  • どうすればよいか: 戻したいときは、窓の上の［くわしく］を押して、［設定］の［閉じたら元のポーズに戻す］にチェックを入れます。残したいポーズは、閉じる前に保存します。

画面の言葉が、英語や韓国語になった

  • どうなっているか: 言語が切りかわりました。
  • どうすればよいか: 窓の上の言語の欄（または［設定］の［言語］）で、「日本語」を選びます。

C# から使う

次の例は、マネキンを出して、指を曲げて、写真を撮ります。

ファイルは、Assets の中の Editor フォルダに置きます。

using GP14;
using UnityEditor;
using UnityEngine;

// 自分のアセンブリ定義（asmdef）を使うときは、GP14.PoseStudio.Editor を参照に足します
public static class PoseSample
{
    [MenuItem("Tools/Pose Sample/Take Photo")]
    static void TakePhoto()
    {
        using (var api = new PoseStudioApi())
        {
            // 練習用のマネキンを出して、ポーズを付ける相手にします
            api.Studio.CreateMannequin();
            var session = api.Studio.Session;

            // 両手の指を、半分だけ曲げます
            session.SetFingerCurl(true, FingerMask.All, 0.5f);
            session.SetFingerCurl(false, FingerMask.All, 0.5f);

            // 足を床に付けます
            session.PlaceOnGround();

            // 写真の大きさと保存先を決めて、撮ります
            var settings = api.Studio.Capture.Settings;
            settings.Width = 1024;
            settings.Height = 1024;
            settings.OutputFolder = "Screenshots/PoseStudio";
            var photo = api.Studio.TakePhoto("camera");
            Debug.Log("保存しました: " + photo.Path);
        }
    }
}

Unity の上のメニューの「Tools」に、「Pose Sample」が増えます。そこから「Take Photo」を選びます。

呼び出し中身引数（既定値）
api.Studio.CreateMannequin()マネキンを出して、編集の対象にします。なし
api.Studio.SelectAvatar(avatar)シーンの人型のアバターを、編集の対象にします。avatar: 人型の Animator
api.Studio.Session.SetFingerCurl(left, fingers, curl, weight)指を曲げます。weight（1）
api.Studio.Session.PlaceOnGround()足を床に付けます。なし
api.Studio.TakePhoto(kind, save)写真を撮ります。kind（"camera": 撮影用カメラ。"scene": シーンビューなど）、save（true）
